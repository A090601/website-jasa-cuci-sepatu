# ShoeWash — Website Jasa Cuci Sepatu

ShoeWash adalah website layanan cuci sepatu yang menyediakan informasi layanan, harga, booking online, pengecekan status pesanan, galeri hasil pekerjaan, dan testimonial pelanggan.

## ✨ Fitur

- Landing page modern dan responsive
- Daftar layanan cuci sepatu
- Daftar paket dan harga
- Booking cuci sepatu online
- Kalkulator harga booking
- Cek status pesanan
- Order tracking
- Galeri before/after
- Testimonial pelanggan
- Integrasi WhatsApp
- Admin dashboard
- Manajemen layanan
- Manajemen harga
- Manajemen booking
- Manajemen galeri
- Manajemen testimonial
- Responsive untuk desktop dan mobile

## 🛠️ Teknologi

- Laravel
- PHP
- MySQL
- Blade
- JavaScript
- Vite
- Tailwind CSS
